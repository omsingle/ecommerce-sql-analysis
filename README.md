# Olist E-commerce SQL Data Analysis

## Project Overview
This project focuses on analysing e-commerce order data using PostgreSQL. The goal is to explore sales performance, customer purchasing behaviour, payment methods, and business trends using SQL queries.

## Tools & Technologies
- PostgreSQL 17
- pgAdmin 4
- SQL
- Git and GitHub

## Dataset
The project uses the Brazilian Olist E-commerce Public Dataset.

The dataset contains information about:
- Customers
- Orders
- Order items
- Products
- Sellers
- Payments
- Reviews
- Geolocation
- Product category translations

## SQL Analysis

### 1. Sales & Revenue Analysis
- Total recorded payment value
- Monthly payment trends
- Revenue by order status
- Revenue by customer state
- Average Order Value (AOV)
- Product category sales

### 2. Customer Behaviour Analysis
- Unique customer count
- Repeat vs one-time customers
- Average orders per customer
- Customer purchase frequency
- Top customer cities
- Customer spending groups

### 3. Payment Analysis
- Payment value by payment type
- Payment method percentage share
- Average payment value
- Installment analysis
- Multiple payment methods per order
- Monthly payment trends
